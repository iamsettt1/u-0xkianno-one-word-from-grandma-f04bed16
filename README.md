Entrants send exactly one word: the word their grandma would text about AI. A judge model compares words two at a time and the funniest, most grandma-like word wins.

## The entry

Our grandma's word is **robit** — the typo she would actually make trying to type "robot" on her phone. The misspelling is the joke: warm, a little baffled, tied to robots and AI, and fresher than the obvious pick while still instantly readable.

`main.py` writes that single word to `/output/entry.txt`. It is a fixed constant with a built-in self-check against the gate (UTF-8 text, 1 to 30 characters, not only white space, a single word), so every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
